## 主要特性

- **UndoRedo 集成**：所有节点/属性操作支持 Ctrl+Z
- **智能类型解析**：`"Vector2(100, 200)"`、`"#ff0000"`、`"Color(1,0,0)"` 自动转换
- **自动重连**：指数退避重连（1秒 → 2秒 → 4秒 ... → 最大60秒）
- **心跳检测**：10秒 ping/pong 保持连接活跃
- **友好的错误提示**：错误响应包含下一步操作建议
