## 场景 6: 快速开始 (35-42秒, 帧 1050-1250)

**画面内容**:
- 标题 "快速开始"
- 5 个步骤带编号圆圈：
  1. 安装插件 - 从 AssetLib 或手动复制
  2. 启用插件 - 项目设置 > 插件
  3. 配置连接 - HTTP 模式，端口 9080
  4. 连接 Claude - 配置 claude_desktop_config.json
  5. 开始使用 - 用自然语言交互

**解说词**:
> 只需要 5 步，你就可以开始使用。
> 第一步，安装插件——可以从 Godot 的 AssetLib 直接安装，或者手动复制到 addons 目录。
> 第二步，在项目设置的插件页面启用它。
> 第三步，配置连接——选择 HTTP 模式，设置端口和身份验证。
> 第四步，在 Claude Desktop 的配置文件中添加 MCP 服务器。
> 第五步，开始使用——用自然语言与你的 Godot 项目交互。

## 场景 8: 架构设计 (48-53秒, 帧 1450-1600)

**画面内容**:
- 标题 "架构设计"
- 三层架构图：
  1. AI Client (Claude等) - 通过 MCP 协议通信
  2. Godot MCP Native 插件 - 原生实现，无需 Node.js
  3. Godot Editor API - 直接调用编辑器功能
- 底部配置信息：HTTP 模式、端口 9080、Token 认证、MCP 1.0 协议

**解说词**:
> Godot MCP Native 采用简洁高效的三层架构。
> 最上层是 AI 客户端，比如 Claude，通过 MCP 协议与 Godot 通信。
> 中间层是 Godot MCP Native 插件，完全原生实现，不需要 Node.js。
> 底层直接调用 Godot Editor API，实现所有编辑器功能。
> 支持 HTTP 传输模式，默认端口 9080，可选 Token 认证，完全兼容 MCP 1.0 协议。
